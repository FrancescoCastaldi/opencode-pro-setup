⬇ Installation

Up and Running in Minutes

Five simple steps. The installer handles everything else.

1

Download the Installer

Get the latest install.exe from the GitHub Releases page, or clone the repository.

PowerShell git clone https://github.com/FrancescoCastaldi/opencode-pro-setup.git
cd opencode-pro-setup
2

Run the Installer

Double-click install.exe and accept the UAC prompt. The installer runs with administrator privileges automatically.

Alternative powershell -ExecutionPolicy Bypass -File install.ps1
3

Choose the Target User

The installer detects all Windows user profiles on your system. You can select which user to install OpenCode PRO for, or use -TargetUser for automation.

Automation powershell -ExecutionPolicy Bypass -File install.ps1 -TargetUser <username>
4

Enter Your API Keys

The installer will prompt for three keys. Have them ready:

Required Keys 🔑 OpenCode Zen API key
🔑 OpenCode Go API key
🔑 GitHub Personal Access Token
5

You're Done!

The installer verifies everything — CLI version, config, plugins, skills, and dependencies. Start OpenCode and enjoy your professional setup.

🔧 Power Users

Install Parameters

Fine-tune the installer behavior with PowerShell parameters.

Parameter Description
-DryRun Simulate the installation without deleting, installing, or writing anything. Safe to preview.
-Force Skip the confirmation prompts. Runs unattended (except API key prompts).
-SkipClean Do not delete existing OpenCode config directories. Re-deploy only your configuration.
-Offline Use only the local config/ folder. Do not download anything from GitHub.
-TargetUser Install for a specific Windows user (e.g. "fracas") without interactive selection. Useful for automation or remote execution.
Example powershell -ExecutionPolicy Bypass -File install.ps1 -DryRun
powershell -ExecutionPolicy Bypass -File install.ps1 -Force
powershell -ExecutionPolicy Bypass -File install.ps1 -SkipClean
